# 🎬 Netflix Data Analysis Dashboard | Power BI

## 📌 Project Overview

The **Netflix Data Analysis Dashboard** is a data visualization project developed using Microsoft Power BI. It explores Netflix movies and TV shows to identify patterns and trends in content, genres, ratings, runtime, and country-wise distribution.

The dashboard presents data through interactive visualizations and slicers, making it easier to explore the content available on Netflix and gain meaningful insights.

## 🎯 Project Objectives

* Analyze the distribution of movies and TV shows.
* Explore content trends across different years.
* Identify the top 5 genres.
* Examine IMDb ratings and runtime.
* Understand country-wise content distribution.
* Build an interactive dashboard for data exploration.

## 📊 Dashboard Features

* **Runtime Analysis:** Explore the runtime of Netflix content.
* **Movies and TV Shows:** Analyze the distribution of both content types.
* **Average IMDb Rating:** Examine the average IMDb rating.
* **Top 5 Genres:** Identify the most prominent genres.
* **Content by Year:** Explore how content distribution changes over time.
* **Country-wise Distribution:** Analyze the geographical distribution of content.
* **Movies vs. TV Shows:** Compare the two content categories.
* **Interactive Slicers:** Filter dashboard visuals to explore specific data.
